# Mariachi Maraca Roach Minecraft Plugin

Mariachi Maraca Roach is a Minecraft plugin for Paper servers that adds a cockroach interaction, a Mexican-style maraca item, mariachi-inspired music, a named Mexican Music Album, and a Persian cat with a scratching animation.

## Install

1. Install Java 21.
2. Use a Paper 1.21.11 server.
3. Build the plugin with Maven:

   ```bash
   mvn package
   ```

4. Copy `target/plugin.jar` into your server's `plugins` folder.
5. Start or restart the server.

## Use

1. Join the server with permission to use the plugin commands.
2. Run `/maraca` to receive a Mexican-style maraca.
3. Run `/cockroach` to summon a marked cockroach.
4. Right-click the cockroach with the maraca in your main hand.
5. The cockroach receives a Mariachi Hat, note particles appear, and a short mariachi-inspired guitar tune plays.
6. A Mexican Music Album is added to your inventory.
7. Run `/persiancat` to summon a named Persian cat. The cat alternates between sitting and scratching with particles and cat sounds.
